مولوی ریاض کریانہ اسٹور — ایپ انسٹالیشن

فائلیں:
- index.html: سافٹ ویئر
- manifest.webmanifest: ایپ کی شناخت اور انسٹالیشن معلومات
- sw.js: آف لائن استعمال
- fonts: جمیل نوری نستعلیق فونٹ
- icons: ایپ آئیکنز

اہم:
1) PWA انسٹال کرنے کے لیے ویب سائٹ HTTPS پر ہونی چاہیے۔ GitHub Pages مفت HTTPS فراہم کرتا ہے۔
2) اس ایپ کا ریکارڈ اسی ڈیوائس اور اسی براؤزر میں محفوظ ہوتا ہے۔ کمپیوٹر اور موبائل کے درمیان خودکار Sync موجود نہیں۔
3) Backup بٹن سے JSON فائل ڈاؤن لوڈ کریں۔ دوسری ڈیوائس پر Restore بٹن سے وہ فائل بحال کریں۔
4) فونٹ اور باقی فائلیں الگ نہ کریں؛ پورا فولڈر GitHub پر اپ لوڈ کریں۔
